Coneckin

Login WiFi kampus dengan satu ketukan. Simpan username dan password sekali, lalu pindah ruangan tanpa mengetik ulang.

Download APK Semua rilis

Membutuhkan Android 10 atau lebih baru.

Cara instalasi

  1. Unduh coneckin.apk dengan tombol di atas.
  2. Buka file yang diunduh. Jika diminta, izinkan Install dari sumber tidak dikenal untuk browser atau pengelola file Anda.
  3. Jika muncul peringatan Play Protect, pilih Install saja. Aplikasi ini dibagikan di luar Play Store.
  4. Ketuk Install, lalu buka Coneckin.

Cara penggunaan

  1. Sambungkan HP ke WiFi kampus lewat pengaturan WiFi seperti biasa.
  2. Buka Coneckin, ketuk Tambah Akun, lalu isi nama akun, username, dan password. Alamat portal sudah terisi untuk kampus ini.
  3. Ketuk LOGIN WIFI. Aplikasi masuk ke portal di latar belakang.
  4. Saat pindah ruangan, cukup buka Coneckin dan ketuk LOGIN WIFI lagi. Satu akun berlaku untuk semua ruangan yang memakai portal yang sama.
Akses lebih cepat

Tarik panel atas HP, ketuk ikon pensil, lalu seret tile Login WiFi ke panel. Satu ketukan membuka Coneckin dan langsung login.

Jika login otomatis gagal

  • Periksa username dan password pada akun yang tersimpan.
  • Ketuk Buka halaman portal untuk login manual, misalnya jika portal meminta langkah tambahan.
  • Jika HP bertanya soal WiFi tanpa internet, pilih Tetap terhubung.

Keamanan dan privasi

  • Username dan password disimpan terenkripsi di HP Anda dan tidak dikirim ke server mana pun.
  • Data hanya dikirim ke halaman login portal yang sudah Anda daftarkan.
  • Tidak ada sambungan otomatis. Login berjalan hanya saat Anda mengetuk tombol.
  • Anda bisa mengunci tombol login dengan PIN, pola, atau sidik jari lewat saklar di aplikasi.
  • Coneckin hanya dipakai untuk akun milik Anda sendiri.
